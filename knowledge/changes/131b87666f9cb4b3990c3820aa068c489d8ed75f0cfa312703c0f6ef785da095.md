## Summary
Builds the canonical text each note is hashed from: a header (kind, commit, tree, parents, author, dates, subject, body) plus the diff. canonicalize() applies exclusion and generated-file rules (header-only chunks with a marker), per-file byte caps and a total cap, then hashes both the whole commit text and each file chunk; recipe_string records every setting that influences the text.
