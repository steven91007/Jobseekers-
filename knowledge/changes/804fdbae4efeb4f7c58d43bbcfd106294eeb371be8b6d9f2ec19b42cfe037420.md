## Summary
Subprocess wrappers around git with user/system config disabled and LC_ALL=C for stable output: rev_list (oldest-first topo), commit_meta via a NUL-separated log format, file_changes from diff-tree --raw and --numstat (renames and binaries handled), patch_bytes with the fixed DIFF_ARGS (--full-index, -U3, --find-renames=50%, fixed prefixes), split_patch and chunk_path. Merges are diffed against the first parent; root commits use --root.
