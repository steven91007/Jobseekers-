## Summary
JobBotClient subclasses discord.Client with default (non-privileged) intents, syncs commands to a dev guild or globally in setup_hook, starts the 5-minute ticker there rather than in on_ready, sweeps subscriptions whose channel returns NotFound, deactivates subscriptions when leaving a guild, and guards the ticker body plus an error handler that restarts the loop.
