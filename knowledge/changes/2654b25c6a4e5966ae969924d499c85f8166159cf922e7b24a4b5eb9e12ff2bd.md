## Summary
The build/index engine. _index_commit_note parses a commit note and its change notes into DB rows (the only path that writes index rows, shared by build and rebuild); index_from_notes rebuilds the whole index from disk oldest-first; build() walks rev-list oldest-first, skips indexed commits, re-indexes commits whose note already exists without calling the summarizer, writes change notes then the commit note atomically, and records failures in BuildStats; pending() exports canonical inputs plus a field guide and answer format for commits still lacking a real summary.
