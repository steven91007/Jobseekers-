# e842eb8 Read report files as UTF-8 in jobagent pipeline tests

## Summary
The two jobagent pipeline tests that read the generated Markdown report now open it as UTF-8, matching how report.write_markdown writes it.

## Why
On Windows the default cp950 codec cannot decode the emoji in the report, so the tests failed with UnicodeDecodeError there while passing on UTF-8 locales.

## Risks
none identified

## Files
- `tests/test_jobagent_pipeline.py` (M, +2/-2): read_text and open now pass encoding='utf-8' when reading the report back. [note](../changes/3404e582fce976190067174b3f9d7853e02ca1d13240f35d43d15b482a33c725.md)

Read report files as UTF-8 in jobagent pipeline tests

report.write_markdown writes with encoding="utf-8", but the two tests that
read it back used open()/read_text() with no encoding. On Windows that is
cp950, which dies on the emoji in the report:

    UnicodeDecodeError: 'cp950' codec can't decode byte 0xf0

The tests pass on a UTF-8 default locale, so this only shows up when running
them on a Windows machine.
