# a12dc36 Refuse to score against a missing or template profile; add `jobagent rescore`

## Summary
jobagent now refuses to score or run the research agent when the candidate profile is missing, empty or still the unedited profile.example.md template, instead of silently falling back to the template. Assessments record a fingerprint of the profile they were made with, and a new `jobagent rescore` command re-scores the ones made with another profile and reports the priority transitions and largest score changes. JOBAGENT_PROFILE accepts absolute paths.

## Why
All 88 existing assessments had been scored against the template (the user's profile.md was an unedited copy and a missing file fell back to it too), so the scores described a fictional candidate while looking plausible.

## Risks
Runs with a missing or template profile now skip scoring and the agent entirely (collection and the report still run). The profile_sha column is added to existing databases on connect. Rescoring spends one OpenAI call per stale job.

All 88 assessments in the local database had been scored against

- load_profile() raises ProfileError when the profile is missing, empty or
  still contains the template's instruction line; there is no fallback.
  run() then skips scoring and the research agent, reports why, and still
  writes the collection report.
- JOBAGENT_PROFILE accepts absolute and ~ paths, so worktrees can share the
  one profile that lives in the main checkout.
- Assessments store profile_sha, a fingerprint of the profile they were made
  with (the column is added to existing databases). score_jobs records it,
  and in Langfuse on the score-jobs span.
- `python -m jobagent rescore [--all] [--limit N]` re-scores assessments made
  with another profile under a rescore-jobs trace and prints the priority
  transitions and the largest score changes. Changes are detected by rowid,
  since INSERT OR REPLACE gives a re-scored row a new one (created_at has
  one-second resolution and missed fast re-scores).
- doctor reports the profile path and fingerprint, or why it is unusable.
- README (en, zh-TW) and .env.example document the profile requirement and
  rescore.
