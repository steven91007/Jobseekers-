# 24db998 Add region presets (Nordics etc.) and visa-sponsorship detection

## Summary
Two user-facing additions. Location lists now accept region presets (北歐/Nordics, 德語區/DACH, 荷比盧/Benelux, 波羅的海/Baltics) that expand into per-country searches. A new visa.py module reads each posting's description and marks whether visa or work-permit sponsorship is offered, quoting the sentence it relied on: multilingual rules decide most cases (negative phrasing checked first), and postings the rules cannot decide go to an optional Claude assist only when ANTHROPIC_API_KEY is configured. The verdict appears in the CLI table, detail view and Excel export, and in Discord through a visa_check flag on /jobs subscribe and /jobs preview; the subscriptions table gains a visa_check column with an additive migration.

## Why
The user asked to cover more countries, specifically the Nordics, and to find out which postings support visas, allowing an LLM to help when the answer is uncertain.

## Risks
Each visa check is one extra LinkedIn request per job, raising block risk; the bot limits it to the jobs it will post. Rules only detect explicit statements, so 不明 means "not mentioned", not "not offered". Region presets multiply searches (Nordics is five), and max_results is a total cap so later countries can be starved. The LLM assist costs money when enabled and its verdicts are marked as such.
