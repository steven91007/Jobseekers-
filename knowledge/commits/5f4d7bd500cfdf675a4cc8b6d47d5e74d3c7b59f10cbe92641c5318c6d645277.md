# f15bc48 Merge origin/agentic-searching-system (jobagent from master) into the MCP work

## Summary
Merges origin/agentic-searching-system (jobagent from master) into the MCP work. Relative to the MCP branch it brings in jobagent and resolves conflicts: one langfuse>=4.15,<5 pin for jobagent and the MCP server, the gitkb and visa sections restored in .env.example with the MCP section reusing jobagent's Langfuse keys, and both README sections kept. It also makes pytest collect tests/ cleanly.

## Why
The remote branch had merged master; the MCP commits had to be integrated with it before pushing, and the combined tests directory crashed pytest at collection.

## Risks
jobagent now runs on Langfuse SDK v4 instead of v3; its Langfuse calls are unchanged in v4 and its tests pass. The MCP checks run in a subprocess under pytest, so failures show as one test with captured output.
