# 0b46f03 init

## Summary
First real code drop: an interactive Rich-based CLI (main.py) that searches jobs on LinkedIn, XING and Indeed Germany through three scraper modules, shows a styled results table and lets the user open a job's detail. The LinkedIn scraper uses the unauthenticated guest API with pagination and an English-only heuristic; the Indeed scraper relies on cloudscraper to get past Cloudflare; the XING scraper parses Next.js data or HTML. Also adds a Claude Code permissions file and PyCharm SDK settings.

## Why
Establish a working multi-platform job search tool for the terminal. The commit message is only "init", so the intent is inferred from the code.

## Risks
All three scrapers depend on undocumented HTML/JSON structures and will break silently when the sites change. The LinkedIn search loop has no upper bound tied to fetch_limit, so english_only filtering can page until the 1000 cap. No tests, no rate limiting beyond a 1 second sleep. Chinese UI strings are hardcoded.
