# 97473b6 Expose posted_within (24h / 7d / 30d) in the MCP search_jobs tool

## Summary
The MCP search_jobs tool accepts posted_within (24h, 7d or 30d), validated and normalized like work_type and job_type and passed to the scraper's LinkedIn date filter.

## Why
The merged scraper gained the f_TPR filter; exposing it lets an agent ask for only recent postings instead of paging past old ones.

## Risks
Narrow date windows on thin markets return empty results, which the scraper reports as EMPTY_SUSPICIOUS rather than EMPTY_OK.
