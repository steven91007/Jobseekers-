# 4bc8390 Move the MCP server to its own repo, mounted as the jobseekers-mcp submodule

## Summary
Moves the MCP server out of this repository into steven91007/jobseekers-mcp (history kept) and mounts it back as a git submodule at jobseekers-mcp/. .mcp.json installs the submodule in editable mode through uv, requirements.txt drops mcp, and tests/test_mcp.py runs the submodule's checks against this checkout.

## Why
The user wanted the MCP server maintained and versioned in its own repository while still wrapping this project's modules.

## Risks
Clones need --recurse-submodules or `git submodule update --init`, otherwise .mcp.json fails to start the server and test_mcp.py skips. The server depends on this repo's module interfaces across a repository boundary, so changes to linkedin_scraper, visa, gitkb or bot.db must be checked with tests/test_mcp.py and the submodule bumped deliberately.
